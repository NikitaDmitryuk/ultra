# 0014 — Подтверждённый тариф Vultr для обновления квот

## Статус

accepted

## Дата

2026-10-03

## Контекст

Обновление квот требовало каталог тарифов при каждом цикле. Недоступность каталога
исключала исправный exit даже при доступных API текущего VPS, остатка аккаунта и
исходящего трафика. Завершённая операция создания уже хранит подтверждённый тариф.

## Решение

Уточняет источник номинального бюджета из [ADR 0010](0010-monthly-quotas-and-route-application.md).
Брать тариф из последней операции `ready`, совпадающей одновременно по instance ID
и exit ID. Использовать её положительный bandwidth в десятичных ГБ только при
совпадении сохранённого plan ID с текущим plan ID VPS; проверять переполнение.
Поля тарифа внутренние, схема БД и публичный контракт бюджетов не меняются.

При отсутствии корректного подтверждённого тарифа или смене plan ID обращаться
к каталогу, не более одного раза за цикл. Неизвестный тариф или отказ этой проверки
оставляет защитную блокировку. `instance.allowed_bandwidth` не заменяет тариф.

Остаток аккаунта и расход экземпляра по-прежнему получать свежими запросами API.
Запас 20%, распределение общего остатка, месячные лимиты и запрет при устаревании
данных более 15 минут сохраняются. Сбой каталога не разрешает старые данные расхода.

## Рассмотренные альтернативы

- Всегда требовать свежий каталог: его отказ блокирует уже установленный VPS.
- Использовать старый расход или вручную снять запрет: ослабляет защиту от перерасхода.
- Добавить отдельный кеш тарифов: дублирует уже сохранённое подтверждение покупки.

## Последствия

Исправный установленный VPS не зависит от доступности каталога при неизменном
plan ID. Изменение характеристик провайдером без изменения plan ID автоматически
не обнаруживается: сохранённый номинальный объём фиксирует подтверждённый тариф,
а свежий общий остаток аккаунта остаётся дополнительным потолком.
После изменения plan ID нужна успешная проверка каталога. Новые тарифы не записываются
обратно в историю покупки; при несовпадении каталог проверяется в следующих циклах.
