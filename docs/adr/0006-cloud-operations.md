# 0006 — Сохраняемые операции Vultr

## Статус

accepted

## Дата

2026-09-07

## Контекст

Нужны создание и замена exit из Mini App без повторной покупки после сетевого сбоя.

## Решение

Worker bridge выполняет подтверждённое предложение до пяти минут с лимитом двух занятых слотов. Стадии и ID провайдера сохраняются в PostgreSQL; неизвестное создание сначала сверяется по метке операции. Непроверенный exit не публикуется. Ручная установка остаётся доступна локально.

## Рассмотренные альтернативы

Ручная форма создания узла в Mini App удалена. Запуск CLI из worker и автоматическая повторная покупка после таймаута не выбраны.

## Последствия

Неисправный VPS не удаляется автоматически и продолжает учитываться как оплачиваемый. Замена требует свободного слота. Требуются выделенные секреты и административное подтверждение актуальной цены.
