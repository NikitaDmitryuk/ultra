# 0011. Отдельный HTTPS-вход подписок

## Статус
accepted

## Дата
2026-09-08

## Контекст
Страница импорта и подписки на bridge:8444 доступна напрямую, но соединение через
WARP отклоняется. В ultra домен исключён из WARP; это не помогает новым клиентам
через чужой VPN. 443 bridge занят прежними VPN-профилями.

## Решение
Сначала проверить существующий домен через свободные 443/8444 существующего Vultr
exit, передавая TLS через HAProxy на bridge:8444. DNS переключать только после
успешных проверок. Боту дать отдельную настройку публичного origin, сохранив
старые URL и токены. HTTP-01 направлять на существующий certbot bridge.

## Рассмотренные альтернативы
Перенос VPN с 443 нарушает совместимость. Копия бота/БД и TLS termination на exit
добавляют секреты и сопровождение. Покупку домена отложить до проверки текущего.

## Последствия
Нет нового VPS или переноса секретов. Доступ зависит от двух узлов; перед
удалением ingress exit необходимо перенести вход вручную. Серверная конфигурация
защищает выбранный ID VPS от удаления и замены в API/worker; UI показывает эту роль. Перенос IP не является
доказанным обходом блокировки домена. HTTP-логи с секретными путями запрещены.
