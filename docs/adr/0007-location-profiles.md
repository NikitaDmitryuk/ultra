# 0007 — Учётные данные локаций одного доступа

## Статус

accepted

## Дата

2026-09-07

## Контекст

Одновременно нужны выбор по умолчанию из Mini App и выбор отдельной страны на конкретном устройстве Happ.

## Решение

Основной UUID сохраняет автоматический профиль. Дополнительный UUID связан с владельцем и стабильной локацией, указывает предпочтительный exit. Замена VPS в одном регионе сохраняет идентификатор локации. Трафик суммируется на владельца, отключение и сброс охватывают все его профили.

## Рассмотренные альтернативы

Отдельные независимые пользователи для стран и глобальная смена страны при выборе профиля одним устройством не выбраны.

## Последствия

Профиль обозначает предпочтение: failover может сменить страну и прервать соединения. Чтение кабинета и подписки не создаёт новые ключи. Старые ручные доступы не привязываются автоматически.
