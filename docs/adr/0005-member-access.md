# 0005 — Закрытый допуск и восстановимая подписка

## Статус

accepted

## Дата

2026-09-07

## Контекст

Пользователям нужен личный доступ без административных прав и повторный импорт той же подписки.

## Решение

Разрешаем первую регистрацию из одной закрытой группы или по именному приглашению на семь дней. Один Telegram ID имеет один доступ; выход из группы после регистрации его не отзывает. Токен хранится как хеш и AES-256-GCM с отдельным версионированным ключом. Это заменяет ограничение ADR 0003 о хранении только хеша.

## Рассмотренные альтернативы

Открытая регистрация, ручное одобрение каждого участника и повторная ротация токена при каждом просмотре не выбраны.

## Последствия

Доступ можно отозвать вручную. Сбой применения сохраняет pending до подтверждения ядром. Нужна отдельная резервная копия ключа; старые hash-only подписки сохраняются.
