# 0010 — Месячные квоты и подтверждённое применение маршрутов

## Статус

accepted

## Дата

2026-09-08

## Контекст

Заменяет [ADR 0009](0009-traffic-budgets.md). Дневное распределение затрудняет
понимание доступного трафика. Номинальный тариф Vultr и начисленные кредиты аккаунта
имеют разные назначения. Сохранённое предпочтение не доказывает применение маршрута;
закрытие слушателя Xray не гарантирует завершение обслуживаемых соединений.

## Решение

Сохранять учёт полезных байтов по фактическому outbound и суммировать все профили на
владельца. Месячный объём Vultr брать из каталога по фактическому plan VPS, в десятичных
ГБ. Начисленный общий остаток аккаунта делить между управляемыми включёнными узлами
пропорционально номинальным бюджетам, не умножая общий кредит на число серверов.

Оставлять 20% запаса. На дополнительном узле личный потолок — 25% месячного бюджета
после запаса. Период — календарный месяц UTC, дневного ограничения нет. Доступно
минимальное из личного остатка и безопасного общего остатка узла. Неактивные пользователи
не резервируют трафик. На основном резерве (Амстердам) действует только общий предел.
История и лимиты сохраняются при ротации UUID. При исчерпании или недостоверных данных
провайдера переводить на Амстердам; при отсутствии допустимого выхода блокировать
туннельный трафик. Существующий split routing сохраняется.

Применение конфигурации сериализовано. API отличает сохранённое предпочтение от
подтверждённого выхода и сообщает ошибку применения. Квоты подтверждаются условным
обновлением именно прочитанного расчёта. После перезапуска требуется новое применение.

При смене конфигурации Ultra завершает потоки старого экземпляра. Для TCP-вариантов
XHTTP Ultra владеет внешними TCP-соединениями и передаёт зашифрованные байты официальному
транспорту через Unix-сокет в приватном каталоге 0700. PROXY-заголовок сохраняет адрес
клиента. Это обход ограничения Listener.Close закреплённого Xray; TLS/REALITY, публичные
порты и подписки не меняются. HTTP/3 использует штатное закрытие сервера. Форка нет.

## Рассмотренные альтернативы

- Дневные квоты по прошлой активности: заменены понятным месячным потолком.
- Неограниченный общий пул: один пользователь может исчерпать весь месячный бюджет.
- Обновление подписки для переключения: не управляет уже открытыми соединениями.
- Форк Xray или доступ к его приватным полям: требуют сопровождения зависимости.
- Точный побайтовый ограничитель: отдельное изменение тракта передачи.

## Последствия

Сохраняются сбор статистики и расчёт квот каждые 30 секунд, обновление данных Vultr
каждые пять минут и запрет при устаревании более 15 минут. Между сбором и применением
возможен перерасход; запас не гарантирует отсутствие дополнительной платы. Замена
общего ядра кратко затрагивает другие соединения. Уже открытый поток не переносится
бесшовно: приложение должно открыть новый. Чтение кабинета не вызывает reload.

Обёртку TCP XHTTP можно удалить после исправления upstream и прохождения теста смены
маршрута с неизменным клиентом, повторно используемым каналом и длительной передачей.
