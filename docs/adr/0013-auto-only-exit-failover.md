# 0013 — Failover только автоматического профиля

## Статус

accepted

## Дата

2026-10-01

## Контекст

Профиль «Автоматически» использовал основной UUID и наследовал сохранённое предпочтение
Mini App. UUID локаций также задавали предпочтение и могли переключаться на другую
страну. Владелец согласовал разделение: Auto выбирает рабочий выход, страна остаётся
фиксированной. Заменяет ADR 0007 и политику резервного выхода при квоте из ADR 0010.

## Решение

Основной UUID — Auto: сохранённое предпочтение аккаунта не влияет на маршрут.
Селектор выбирает active exit по priority и health с существующим окном возврата.
Если active запрещён квотой пользователя, выбирается исправный разрешённый exit
с минимальным priority, затем ID. При отсутствии допустимого выхода трафик блокируется.
Кабинет показывает подтверждённый выход и не предлагает выбор страны для Auto.

UUID локации явно отмечается как фиксированный при раскрытии маршрутов: сетевой отказ
сохраняет его outbound, квота или отсутствующий/отключённый exit блокируют его трафик.
Отсутствующий ExitID не превращает удалённую локацию в Auto. Замена exit у той же
локации сохраняет UUID. Формат подписки и сохранённые legacy-предпочтения не меняются;
старый API записи предпочтения сохраняет данные, но не меняет маршрут Auto.
Существующие правила split routing сохраняются.

## Рассмотренные альтернативы

- Предпочтение Mini App для Auto: отклонено владельцем, Auto должен зависеть от доступности и priority.
- Резерв для фиксированной страны только по квоте: отклонён, профиль не должен менять страну.
- ICMP вместо передачи через туннель: не доказывает доступность пользовательского пути.

## Последствия

Фиксированный профиль может оставаться недоступным; для резерва пользователь выбирает Auto.
Auto учитывает квоты каждого exit и может использовать другой разрешённый узел вместо
прежнего единственного fallback. Новые ключи, миграции и обновление подписки для переключения
не требуются. Два отказа исключают exit, три успеха восстанавливают; возврат общего active
требует 60 секунд устойчивости. Применение конфигурации может прервать соединения.
