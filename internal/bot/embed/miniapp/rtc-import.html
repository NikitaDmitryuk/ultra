Подключение для белых списков

Откройте эту страницу по кнопке из личного кабинета.

Добавить в приложение

Подтвердите открытие установленного приложения и добавление подписки. Затем выберите подключение и включите его.

Если приложение не открылось, вернитесь в кабинет, нажмите «Скопировать профиль» и импортируйте его в приложении из буфера обмена.
